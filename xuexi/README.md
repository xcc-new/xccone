# 五年级上册单词卡（人教PEP版）

一个纯前端的英语单词学习工具，支持单词卡翻转、看词选义、看义选词、听音选词、拼写练习 5 种模式，带间隔重复算法（SM-2）。

## 本地音频

所有单词发音已内置为本地 MP3，存放在 `audio/` 目录下，按单元分文件夹：

```
audio/
├── Unit1/   (26 个单词)
├── Unit2/   (24 个单词)
├── Unit3/   (23 个单词)
├── Unit4/   (22 个单词)
├── Unit5/   (23 个单词)
└── Unit6/   (26 个单词)
```

- 共 144 个 MP3，美音
- 单词发音优先播放本地 MP3，断网也能读
- 课文长句（没有单独 MP3）会自动走在线 TTS 降级

## 上传 GitHub 直接使用

### 方式一：GitHub Pages（推荐）

1. 新建仓库（比如 `pep5-words`），把以下内容一起上传：
   - `index.html`
   - `audio/` 整个文件夹
2. 仓库 → Settings → Pages → Source 选 `main` 分支 / 根目录 `/`
3. 等 1 分钟，访问 `https://你的用户名.github.io/pep5-words/` 即可

### 方式二：直接打开

双击 `index.html` 就能用，音频相对路径已配好，无需服务器。

## 技术说明

- 无构建、无依赖，单 HTML 文件
- 学习进度存在浏览器 localStorage 里
- SM-2 间隔重复算法自动安排复习
- 移动端适配，支持触摸滑动、振动反馈
